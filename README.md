# House Price Prediction Using Linear Regression

## Overview
This project builds a simple regression model to predict housing prices using key socioeconomic and housing-related features.  
The objective is to demonstrate basic predictive modeling and model evaluation skills using Python.

---

## Data
- Source: California Housing dataset
- The dataset includes housing information across California districts.
- Variables used in this project:
  - Median income
  - Housing median age
  - Total number of rooms
  - Median house value (target)

---

## What This Project Does
- Loads and cleans a real-world dataset
- Selects relevant features for prediction
- Splits the data into training and testing sets
- Trains a linear regression model
- Evaluates model performance using R² and RMSE

---

## Tools & Libraries
- Python
- Pandas
- Scikit-learn

---

## Model Evaluation
- R² Score indicates how well the model explains the variance in house prices
- RMSE measures the average prediction error magnitude
